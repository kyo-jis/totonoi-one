# Totonoi One 料金・課金モデル 仕様変更メモ

*作成: 2026-07-23 / 出所: 紹介LP検討セッションで決定した方針。実装は本メモをもとにアプリ開発側で別途対応する。*

---

## 1. 背景・方針転換

- **しばらく全機能を無料開放して認知を拡大 → あとで有料化を実装**する2段階戦略。
- 課金の境界を「**機能解除**（現行 Totonoi Pro ¥480/月）」から「**クラウド自動保存**（実際にサーバコストがかかる部分）」へ転換する。
- ターゲット層（家計簿・サブスク・筋トレ勢）は課金に渋いため**なるべく安価に**。サブスクを増やしたくない層には**年額**が刺さる想定。

## 2. 新しいプラン定義

| | 無料プラン | 保存プラン（有料） |
|---|---|---|
| 料金 | ¥0 | **月 ¥200 / 年 ¥1,500**（実質 ¥125/月・約25%オフ） |
| 全10アプリの全機能 | ✓ | ✓ |
| 登録上限 | **なし（撤廃）** | なし |
| 端末内保存（localStorage） | ✓ | ✓ |
| 手動バックアップ（エクスポート/インポート） | ✓ | ✓ |
| **クラウド自動保存・複数端末同期・自動バックアップ** | — | ✓ |

### 価格決定の根拠
- ¥100 と ¥200 で「毎月払う」心理ハードルはほぼ同じ。¥100 は Stripe 手数料（〜3.6%＋）で目減りが大きく薄利。→ **¥200 を採用**。
- サブスク嫌い層には「年に1回のデータ保険料」= **年額 ¥1,500** が刺さる。月額はアンカーとして併記し、年額を推す。

## 3. フェーズ分けと実装タスク

### フェーズ1（今すぐ・認知拡大期）
- [ ] **各アプリの登録上限を撤廃/無効化**
  - 現行上限: Subly 5 / Medly 10 / Fitly 保存メニュー 3 / Stockly 10 / Renewly 10 / Bookly 20 / Cookly 20 / Readly 30（Kakely・Learnly は元々無制限）
- [ ] **Fitly 分析ダッシュボード / データエクスポート / 購入履歴（全期間）** も無料開放
- [ ] **¥480 アップグレードの課金UIを撤去 or 非表示**（`index.html` の Pro カード・`startCheckout()` など）
- [ ] **`guide.html` の Pro 比較表**を「今は全機能無料」に更新
- [ ] クラウド同期は当面そのまま**無料継続**（ログインで同期）
- [ ] **広告の扱いを決定**（現状「無料=広告あり」→ 消すか残すか）※**未決**

### フェーズ2（後日・有料化実装期）
- [ ] **Stripe**: 保存プランの Price を新設（月 ¥200 / 年 ¥1,500 の2つ）、旧 ¥480 Price は廃止
- [ ] **クラウド自動保存・複数端末同期・自動バックアップ**を保存プラン加入者限定にゲート化
- [ ] **手動バックアップ（エクスポート/インポート）は無料のまま維持**（無料ユーザーのデータ喪失を防ぐ安全弁）
- [ ] `isPro` 判定 → `isSaver`（保存プラン加入）へ再定義。各アプリの `syncFromCloud()` / `dbSave()` を課金ゲートに接続
- [ ] `db/`: `profiles.is_pro` を保存プラン状態カラムへ設計変更
- [ ] **既存ユーザーの移行措置**（これまで無料でクラウド同期していた人の扱い＝グランドファザリング）を決定 ※**未決**

## 4. 触るファイル（参考・現行構成より）

- `api/`（Stripe: `create-checkout-session` / `webhook`）— 価格ID
- `index.html` および各 `*.html` — `isPro` 判定・登録上限判定・課金UI
- `guide.html` — Pro比較表
- `db/` — `profiles` の課金状態カラム

## 5. 未決事項（別途要決定）

1. **広告**を無料で消すか、残すか
2. **クラウド同期**を今も無料のままにするか、フェーズ2で保存プラン限定にするか（限定にすると無料ユーザーは localStorage＋手動バックアップのみになる）
3. **年額 ¥1,500** で確定か
4. **既存の Pro / 同期ユーザー**の移行措置
